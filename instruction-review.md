# HOW INSTRUCTIONS SHOULD BE WRITTEN

*Especially when written by AI*

Apply these criteria to instructions, including this file:

1. Keep only useful guidance the model would otherwise lack
2. Prefer describing desired behavior over listing prohibitions
3. State goals and essential constraints while leaving methods and options open. Use examples sparingly and present them as possibilities, not boundaries
4. Use the shortest wording that preserves the full intended meaning and has one clear interpretation
5. Before saving a general rule, check whether it applies only to a specific task

# CODE REVIEW AND OPTIMIZATION

1. Always aim to simplify code and unify similar patterns while preserving required behavior
2. Increase complexity only with the user's explicit permission, after explaining why it is needed
